# Yaour'na - Website Project

Bienvenue sur le dépôt du site officiel de **Yaour'na**, la marque de yaourt naturel qui fait la fierté du Tchad ! 🇹🇩

Ce projet est une **Landing Page moderne, responsive et animée**, développée avec HTML5, CSS3 et JavaScript. Le design s'inspire des principes de l'UX Tubik, offrant des micro-interactions fluides et une interface utilisateur premium.

## 🌟 Fonctionnalités
- **Animations au défilement (Scroll Reveals)** : Les éléments apparaissent avec une fluidité exceptionnelle.
- **Design Responsive** : Optimisé pour tous les écrans, du mobile aux écrans ultra-larges.
- **Typographie Moderne** : Utilisation des polices Google 'Outfit' et 'Caveat'.
- **Accessibilité (a11y)** : Navigation au clavier optimisée et attributs ARIA.
- **Performance** : Styles légers sans framework lourd.

## 🚀 Lancement Rapide
Pour visualiser le projet localement :
1. Clonez ce dépôt.
2. Ouvrez le fichier `index.html` dans n'importe quel navigateur web moderne.
